Date: 25 October 2026. Baseline: the attached
`AG_Astro_Motion_Studio_V1.3.1_Performance_Hotfix(2).zip`.

## Implementation

The new source continues directly from the supplied V1.3.1 hotfix. Source image
loading/precision, detection/catalog extraction, original RGB sprites, protection
mask generation and Numba compositing modules are unchanged. Changes are focused
in GUI state, camera/depth rendering and video time sampling, with a new
`motionstudio/cinematic.py` module.

Completed: optional simplified Cinematic Mode; four presets and main sliders;
geometry-based strength; soft, overlapping data-driven nebula depth bands;
bilateral smoothing and depth contrast; cubic camera paths; center locking using
the processed depth at the image center; subtle drift; push/pull/side presets;
continuous individual star depths; foreground depth limiting; depth-weighted
motion blur; weak atmosphere/haze; all four loop options; custom duration;
animated low-resolution loop preview; schema 5 persistence; safe reset and
symmetric incompatible-input replacement.

Manual depth sculpting, user-picked subject anchors, a separate Volumetric Look
mode and more complex path editing remain deferred, as lower/later priorities.
This release does not claim physically reconstructed nebula volumes.

## Reproducible synthetic performance and loop evidence

Run:
`python tests/validate_v14.py --output /tmp/astro-v14`

The seeded fixture draws 1,500 stars and detects **1419** sources
(some drawn sources overlap). It uses a 1280×720 generated texture as a renderer
exercise, not a real astrophotograph. Both paths keep the same complete catalog;
Cinematic Strength 110%, Atmosphere 30%, Seamless Drift, blur 15%.
Compilation/initial frame warm-up is excluded from five timed frame samples.

| Path | Output | Median frame time | Scene preparation |
|---|---|---:|---:|
| Fast Preview | 640×360 | 24.75 ms | 210.25 ms |
| Final quality | 1280×720 | 131.75 ms | 199.47 ms |

Fast Preview was **5.32× faster per frame** in this
specific comparison. This includes its lower resolution, reduced layer iterations
and two rather than four blur exposures. It is not a benchmark against V1.3.1,
a promise for every input, or a full-resolution dense-field stress test.

- Exact t=0/t=duration pixel error, including blur history: **0**.
- Mean 8-bit channel step across the exported wrap: **0.856289**.
- Mean channel step across the next regular frame: **0.855192**.
- Included demo: 5 s, 24 FPS, 120 frames, 640×360, libx264, 2 frame workers.

Raw values are in `examples/benchmark_v14.json`. Four rendered times are in
`examples/cinematic_contact_sheet.png`; the reproducible animation is
`examples/cinematic_loop_demo.mp4`. These demonstrate smooth periodic sampling,
not a guarantee of identical quality for arbitrary user artwork or extreme poses.

## Environment and limits

Host: Linux, Python 3.12.14, CPU rendering/encoding.

Dependency versions exercised:

- numpy: 2.3.5

- PyQt6: 6.11.0
- numba: 0.68.0
- imageio: 2.38.1
- imageio-ffmpeg: 0.6.0
- astropy: 8.0.2
- tifffile: 2026.10.15
- pytest: 9.1.1

Native Windows/macOS installers and desktop interaction, real NVENC/Quick Sync/
AMF hardware, optional AI weights/downloads and the user's own starless/mask pair
were not exercised. No user source pair was included in the supplied package.
The preserved historical demo does not substitute for such inputs. Rendering
performance and appearance should be checked on the intended machine and images.

Known artistic limitations: strong depth/camera angles may produce 2.5D stretching,
layer ghosting and reflected borders; no disocclusion inpainting is performed.
Center locking uses the image center, not semantic object detection, and cannot
keep an entire large target inside extreme zoom/FOV framing. Closed Orbit/Drift
use keyframe extents instead of following arbitrary intermediate poses. Loop
preview has a 240-frame memory cap and lowers FPS for very long custom durations.
All blur/haze samples derive from existing image data; star count is unchanged
unless the existing explicit synthetic-star option is enabled.
